# Box Model: дві навчальні картки

Навчальна сторінка на чистих HTML і CSS з двома картками. Мета: показати, як розміри, відступи та просте позиціювання впливають на вигляд блоків.

## Що використано

| Властивість | Де і для чого |
|-------------|---------------|
| `box-sizing: border-box` | Глобальний ресет `*, *::before, *::after`: `padding` і `border` входять у задану ширину |
| `padding` | Картка 1: `48px 24px 24px` (зверху більше місця під позначку). Картка 2: `12px` |
| `border` | Картка 1: `2px solid`. Картка 2: `6px solid` |
| `margin` | Картка 1: `24px auto`. Картка 2: `48px auto 24px`. Значення `auto` по боках центрує картки |
| `max-width` | Обидві картки обмежені до `360px` |
| `position: relative` / `absolute` | Картка 1 є точкою відліку, позначка «Нове» позиціонується через `top` і `right` |
| `overflow`, `overflow-wrap` | Вміст не виходить за межі карток, довгі слова переносяться |

## Структура


## Запуск

Відкрийте `index.html` у браузері. Для публікації увімкніть GitHub Pages: **Settings → Pages**, оберіть гілку `main` і кореневу папку.

## Перевірка

Розміри двох карток і позиціювання позначки перевірено в DevTools. На вузькій ширині позначка не перекриває заголовок, а горизонтальний скрол сторінки відсутній.
